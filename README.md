# وثائقي

محفظة شخصية للجواز والهوية ورخصة القيادة: تتابع تواريخ الانتهاء وتنبّه قبلها.

- تشفير AES-256 على الجهاز (PBKDF2 + AES-GCM عبر Web Crypto)، والبيانات تُحفظ في IndexedDB داخل المتصفح فقط.
- إضافة وتعديل وحذف المستندات مع صور الوجهين، وبحث وتصفية حسب الحالة والنوع.
- قلب البطاقة لعرض الوجه الخلفي، وحفظ المستند كملف PDF بمقاس البطاقة الفعلي (85.6 × 53.98 ملم).
- نسخة احتياطية مشفّرة واستعادتها على جهاز آخر.

التطبيق ملف واحد `index.html`، يُفتح مباشرة أو عبر GitHub Pages.
